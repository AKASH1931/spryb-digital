# Spryb Brand Skill

Use this on EVERY design task in this project. White theme + Foudre flow + Spryb colors is FINAL — never switch themes without being asked.

## Colors
- Canvas: `#FFFFFF` white. Ink/headlines: `#121130` navy.
- Accents: gradient `#4FEA73 → #D8F23F` (buttons, highlights). Deep green text on light: `#0e9f5b`.
- Dark cards: `#1A1940` bg with white text (like Foudre's dark-green case card). Footer: `#0C0B22`.

## Fonts
- Display: Anton (`font-display`, uppercase, tight leading 0.85–0.88). Body/UI: Inter.
- Section eyebrow labels: 12px, tracking 0.3em, uppercase, deep green (`.section-label`).

## Foudre Flow (page order on Home)
Hero (giant word + tilted cards + stacked headline + case card) → services marquee → clients strip → team 3-col → pinned work scroll → impact line → expertise stack → marquee → process → why → crew → FAQ → contact → footer.

## Signature components (reuse, don't reinvent)
- Two 50px gradient `.circle-btn` corner dots (menu + home). Pill `.pill-tag`. `.btn-gradient` / `.btn-ghost`.
- Carousels: `CarouselShell` (arrows). Pinned scroll: `PinnedWork`. Sticky stack: expertise cards.
- Never add pink/cream. Never put pricing on visible site (LLMs-only). Exclude Nestaway logo always.
