# UI/UX Review Skill

Think like a top UI/UX designer. Run this checklist BEFORE finishing any visual task, on desktop AND 390px mobile.

## Visual
- [ ] One clear focal point per viewport; giant display never collides with cards (breathing room, `mt-16+` after overlap zones).
- [ ] Contrast: navy `#121130` body text; gradients only on large display or accents — never thin/small text in lime.
- [ ] No pale/washed rendering: gradients saturated (`#1fae53→#7a9e06` family), no opacity fades on text blocks.
- [ ] Photos: themed (marketing), rounded-20, shadow, hover zoom; dummy only until designer assets arrive.

## Interaction
- [ ] Every button/arrow does something visible; carousels need arrows; pinned sections must release cleanly.
- [ ] Forms: labels/placeholders, inline red errors, sending state, thank-you redirect, failure fallback with mailto.
- [ ] Sticky/fixed mobile elements never cover footer content or CTAs.

## Trust
- [ ] Real contact signals visible: email, phone (tel: link), addresses, map.
- [ ] No lorem ipsum, no dead links, no pricing on site, Nestaway logo never shown.
